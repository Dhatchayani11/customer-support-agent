# Return and Cancellation Policy

## Return Requests

A return request must be evaluated against the product category,
purchase date, delivery date, and applicable return conditions.

The return window and eligibility rules must be verified from
an approved policy source before confirming eligibility.

## Order Cancellation

Cancellation depends on the current order status and whether
the order has entered fulfillment or shipping.

An order that has already shipped must not automatically be
described as cancellable.

Support must explain the applicable options only after checking
the order status and approved policy.
